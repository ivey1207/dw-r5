# DeltaWing DW-R5 — просмотрщик (WebXR)

Промежуточная версия модели DW-R5: обновляется по ходу работы.

- В браузере: вращение мышью или пальцем, нажатие на деталь показывает её карточку.
- В VR-очках (Meta Quest и аналоги): откройте ссылку во встроенном браузере очков и нажмите «Открыть в VR-шлеме · 1:1».

Модель 1:1, единицы — метры. three.js r170 (MIT).
